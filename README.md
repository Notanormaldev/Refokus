# Refokus — Website Clone

A pixel-perfect, responsive clone of the [Refokus](https://refokus.com) digital agency website, built with React and Vite. This project replicates the modern design, smooth animations, and interactive UI of the original site.

---

## 🚀 Live Demo

🔗 [refokus-notanormaldev.netlify.app](https://refokus-notanormaldev.netlify.app/)

---

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| **React** | Component-based UI development |
| **Vite** | Lightning-fast dev server & build tool |
| **Tailwind CSS** | Utility-first styling |
| **Framer Motion** | Smooth UI animations |
| **JavaScript (ES6+)** | Core logic & interactivity |

---

## ✨ Features

- Faithful recreation of the Refokus agency website layout and design
- Smooth scroll-based and hover animations
- Fully responsive across desktop, tablet, and mobile
- Component-based architecture for easy scalability
- Fast load times powered by Vite's optimized build pipeline
- Marquee / ticker sections and interactive card components

## 🏁 Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) (v16 or higher)
- npm or yarn

### Installation

1. **Clone the repository**

```bash
git clone https://github.com/Notanormaldev/Refokus.git
cd Refokus
```

2. **Install dependencies**

```bash
npm install
```

3. **Start the development server**

```bash
npm run dev
```

4. Open your browser and visit `http://localhost:5173`

### Build for Production

```bash
npm run build
```

The optimized output will be in the `dist/` folder.

## 🌐 Deployment

This project is deployed on **Netlify**. To deploy your own version:

1. Push your code to GitHub
2. Connect the repository to [Netlify](https://netlify.com)
3. Set build command: `npm run build`
4. Set publish directory: `dist`
5. Deploy!
